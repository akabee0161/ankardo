# カタログサイト ビジュアルデザイン方針

## 背景

`site/` は Next.js + React の構成のみで、CSS/デザインシステムが一切導入されておらず、素の HTML 要素にスタイルが当たっていない状態だった。子供向けインディーゲームカタログとして、視覚的な方向性(トーン&マナー・配色・カード構成)を先に固める。

## スコープ

このドキュメントはビジュアルデザインの方針のみを扱う。CSS実装手段(Tailwind CSS 導入の是非など)は別途検討する。

## 想定閲覧者

子供本人と保護者の両方。子供には楽しさ・わかりやすさ、保護者には情報の見やすさ・信頼感の両立を狙う。

## トーン&マナー

**ミニマル・モダン。** 白地×余白を基調とし、アクセントカラーで要素を引き立てる構成。過度な装飾(レトロゲーム風のドット表現や原色多用のポップ路線)は採用しない。

## カラー戦略

- UI基調(ヘッダー・ボタンなど共通要素)はニュートラルな1色に統一する。
- ゲームカードのアクセントカラーは**ジャンルごとに色分け**する。子供にも直感的に伝わる連想を優先する。
- ジャンル分類はやや多め(5〜8種)を想定。以下は初期の仮割り当てで、ジャンルが増減・変更されたら随時見直す。

| ジャンル | 色 | カラーコード(仮) |
|---|---|---|
| アクション | オレンジ | `#FF7A45` |
| パズル | ブルー | `#2F80ED` |
| アドベンチャー | グリーン | `#43A047` |
| リズム/音楽 | ピンク | `#EC407A` |
| レース | イエロー | `#FFC107` |
| シューティング | パープル | `#7C4DFF` |
| 育成/シミュレーション | シアン | `#26C6DA` |

## タイポグラフィ

Webフォントは読み込まず、OS標準のシステムフォントを使用する。表示速度を優先し、ミニマル方針とも相性が良いための判断。

## 一覧ページ(`/games`)のゲームカード

現状(タイトル・ジャンル・小さい画像のみ)から情報量を増やす。

- 画像を大きく表示し、ビジュアルの比重を増やす
- ジャンルタグを表示(上記カラー戦略に従う)
- タイトル
- 説明文を1〜2行表示(既存の `description` フィールドを流用)
- メタ情報バッジ(対象年齢・プレイ人数・難易度)を表示

一覧カードには横スワイプカルーセルは**含めない**(個別詳細ページのみに配置する)。

## 個別ゲーム詳細ページ(`/games/<slug>`)

- メインビジュアルを大きく上部に配置
- メインビジュアルの下にサムネイル画像を横並びで配置し、タップ/スワイプでメイン画像を切り替えられるようにする(Steamのゲーム詳細ページのギャラリーに近い構成)
- 操作方法を説明するテキスト(「スワイプで切り替え」等)は表示しない。UIの見た目だけで直感的に伝わることを狙う
- ジャンルタグ + メタ情報バッジ(対象年齢・プレイ人数・難易度)
- タイトル
- 説明文
- プレイボタン(既存の `playUrl` へのリンク)

## データモデルへの影響(参考、実装は別フェーズ)

現状の `Game` 型(`site/lib/games.ts`)は `slug` / `title` / `description` / `playUrl` / `screenshot?` のみで、以下が不足している。実装計画のタイミングでスキーマ拡張を検討する。

- ジャンル(`genre`)
- 対象年齢(`ageRange` 等)
- プレイ人数(`players` 等)
- 難易度(`difficulty` 等)
- 複数画像対応(`screenshot?: string` → `images: string[]` 等、ギャラリー用)

## 未決事項 / 今後の調整余地

- ジャンルと色の最終的な割り当ては仮決定であり、実際のジャンル一覧が固まった時点で見直す
- CSS実装手段(フレームワーク選定など)は別セッションで検討する
