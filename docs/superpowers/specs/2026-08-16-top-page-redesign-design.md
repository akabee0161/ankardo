# トップページ再設計 方針

## 背景

現状のトップページ(`site/app/page.tsx`)はタイトル・説明文・「ゲーム一覧を見る」ボタンのみの構成で、実質的にゲーム一覧ページへの中継ページになっている。ゲーム一覧ページと差別化された「サイトの顔」としての魅力を持たせる。

## スコープ

このドキュメントはトップページ(`/`)のみを対象とする。ゲーム一覧・個別ゲーム詳細ページ、ヘッダー/フッター等の共通ナビゲーションは対象外。

## 想定閲覧者

子供本人と保護者の両方(半々)。子供には楽しさ、保護者には選びやすさ・信頼感を意識する。

## 検討した案と採用方針

以下3案を検討した。

1. **ジャンルカラー主導のブランドヒーロー型**(採用)— 既存のジャンルカラー(7色、AA配慮済み)をCSSのみで活かし、追加のビジュアルアセットなしで着手できる。ゲーム1件の現状でも成立し、ゲームが増えるほど効果を発揮する。
2. **データ駆動「新着・おすすめ」ダッシュボード型**(見送り)— ゲームが数件〜十数件揃ってから効果を発揮する構成のため、現状ゲーム1件では「新着」セクション等が早期には映えない。ゲーム数が増えた段階(目安5件程度)で再検討する。
3. **ジャンル別ナビゲーションハブ型**(見送り)— `/games` 側にジャンル絞り込み機能が未実装のため、単体では「一覧への入り口を作るだけ」に留まり効果が限定的。

案1をベースに、案3の「ジャンルタイル」要素を部分的に取り込む。

## ページ構成

1. **ヒーローセクション**
   - キャッチコピー(子供にも保護者にも伝わる短い一言)+ サブテキスト(一言サイト説明)
   - 背景はジャンルカラー(7色)を使ったCSSグラデーション/幾何学模様。イラストアセットは使わない
2. **ピックアップゲーム**
   - `featured: true` が設定されたゲームを大きめカードで表示(1〜3件)
   - `featured` なゲームが0件の場合は、全ゲームの先頭(`getAllGames()` の順序)からフォールバック表示する。ゲーム数が少ない現段階でもセクションが空にならないようにするため
3. **ジャンルから探す**
   - 7ジャンルの色タイルを並べる。クリック先は `/games`(ジャンル別フィルタは一覧ページ側に未実装のため、現段階では単純遷移とする)
4. **保護者向け一言**
   - 「対象年齢・ジャンルで選べる」という既存機能(`MetaBadges`/`GenreBadge`)を根拠にした一文のみ記載する。広告有無など未確認の主張は含めない

## データモデルへの影響

`Game`型(`site/lib/games.ts`)に `featured?: boolean` を追加する。バリデーションも拡張し、未設定は「featuredではない」として扱う(必須フィールドにはしない)。

## トーン&マナー

既存の「ミニマル・モダン」方針(`docs/superpowers/specs/2026-08-13-catalog-site-visual-design.md`)を踏襲する。過度な装飾は避け、ジャンルカラーはアクセントとして使う。Webフォントは読み込まない(既存方針を継続)。

## 未決事項/今後の調整余地

- ヒーローのキャッチコピー文言は実装時に具体案を出して確定する
- ジャンルタイルをクリックした際にジャンル別に絞り込む機能(`/games?genre=xxx` 等)は今回のスコープ外。将来的に一覧ページ側の改修として検討する
- 「新着ゲーム」等のデータ駆動ダッシュボード要素(案2)は、ゲーム数が増えた段階で改めて方針を検討する

## 必要なビジュアルアセット(長期バックログ)

現時点でビジュアルアセットは一切なく、本方針(案1)は追加アセットなしで着手可能。ただし以下は用意できれば完成度が上がる項目として、長期バックログに回す(`HANDOVER.md` の Long-term Backlog セクションに記録、ユーザーから話題が出るまで着手しない)。

- ファビコン(`site/app/icon.png` 等)
- サイトロゴ/ワードマーク(SVG1点、現状はテキストの `Ankardo` 表記で代替)
- ジャンルアイコン(7種、ジャンルタイルに添える簡易アイコン。現状は色+ラベルのみで機能する)
- マスコットキャラクター等のイラスト(案1では前提にしていない。将来イラスト主導のブランド強化を行う場合に必要)
