## 分かったこと（forge 本体の README に戻す候補）

- ものの絵（`object`）の背景は白でなく、クリーム・肌色・茶色になることが多い。`background: colors` は白（全チャンネル 240 以上）と `clear_colors` に当たる色しか消さないので、`clear_colors` が無いと何も消えない（書き出しは成功し、透明な画素が 0% になる）。書き出しの後に、透明な画素の割合を見ること
- 背景除去モデル（`matte`）はキャラクター用で、赤く丸い物（りんご・トマト・てんとうむし・にんじん）の絵では、絵によって全面を背景と判定して全面透明になる。同じ種類の別の候補では成功することがあり、候補のページの「背景を消した絵」だけでは気付きにくい。そうなったものは、背景色が単色なので `colors` に `clear_colors`（`{min: 175, max_rg: 40, max_gb: 35}`）を付けると消せた
- `erase` は `matte` の絵にだけ効く（`colors` には効かない）。足元の影が足の輪郭と同じ色でつながっているときは、輪郭にかからない範囲だけを消すしかない
- 「影・床・色付きの背景」を `negative` に書いても、影や足元の楕円は出る。タグでは防げない
- ものの絵は、描かれる大きさがものでばらつく（枠に占める長い辺が 31〜91%）。`box: null`（全体を縮める）のままだと、カードに並べたとき小さいものが小さく見える。書き出しの絵の不透明な範囲の外接の正方形（長い辺が枠の 90%、片側の余白 5%、元の絵の外にはみ出すときはずらす）を `box` に書くと、そろう。小さいものは元の絵から切り出して拡大するので、書き出した絵から切り詰めるより粗くならない

## このゲームだけの変更

- `src/artgen/modal_app.py` の `APP_NAME` を `ankardo-chiiku` にした。forge 本体の Modal アプリと名前がぶつからず、一覧やデプロイで見分けられるため
- `VOLUME_NAME` は `illust-asset-forge-models` のままにした。モデルと版が forge 本体と同じなので、同じ Volume を使えば約 7GB を取り直さずに済むため。入っているのはモデルのキャッシュだけで、生成物は入らない

## forge に戻す候補

ここでエンジン・規約・道具を直したら、何を・なぜ直したかを1行足す。

- `templates/object.yaml`: ものを 1 つだけ描くテンプレート。人物の顔・全身のほかに、物・動物・食べ物の絵を作れるようにするため
- 採用・書き出し・取り込みで受け付ける元の絵の名前を、「`face` と表情は今のまま、それ以外のテンプレートは `templates/<名前>.yaml` ごとに `<名前>.png`」にした（`selected_name`・`_accepted_names`）。テンプレートを足すたびに道具を直さずに済み、`face.png` が無いキャラクターも書き出せる
